# Agent instructions

Keep this standalone launcher independent of application data and deployment settings. Never track private vendor identities,
personal information, credentials, local profiles, model weights or logs. Use fictional examples and environment variables.

Work on `main`. Run the tests and static checks documented in CONTRIBUTING.md before committing. Do not start an inference
server as part of verification. Commit only intended files and push only on explicit request.

Follow PUBLICATION.md. Run Argus on both the working tree and complete history, and keep its local Git hooks installed. Missing
private policy or unreadable content blocks publication. Never bypass a hook, grant an exception yourself, rewrite shared
history or publish a repository without the owner's authorization.
